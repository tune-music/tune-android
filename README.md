# Tune для Android

Нативный клиент Яндекс Музыки для Android 8.0 и новее на Kotlin (Android Views и Media3).

[Сайт](https://tune-music.github.io/tune/) · [Скачать APK](https://github.com/tune-music/tune-android/releases/latest) · [Тестовая сборка (dev)](https://github.com/tune-music/tune-android/releases/tag/dev)

> Тестовая версия (`dev`) устанавливается рядом со стабильной и обновляется отдельно.

## Возможности

- **Главная и поиск:** «Для вас», «Тренды», «Моя волна», колесо настроения, анимированная карточка слов, станции, быстрый доступ и офлайн-волна. Подсказки, история запросов, отдельные вкладки, поиск подкастов и поиск по тексту песни.
- **Плеер и звук:** мини-плеер и полноэкранный плеер с жестами, синхронный текст на месте обложки, очередь, таймер сна, скорость с настройкой высоты тона, эквалайзер, реверберация, нормализация и кроссфейд.
- **Коллекция и страницы:** последние релизы, знакомые треки и концерты на странице исполнителя, альбомы по дискам, плейлисты, лайки, дизлайки, история, статистика и скрытые исполнители.
- **Загрузки и офлайн:** фоновая очередь с прогрессом, паузой и повтором, автозагрузка, офлайн-воспроизведение, учёт места по исполнителям, отдельные настройки качества потока и загрузки по Wi-Fi.
- **Дополнительные функции:** Ynison и Яндекс Станции, версии без цензуры, замена аудио и метаданных, загрузка личных файлов, импорт плейлистов из текста или файлов, экспорт списка в буфер и экспорт аудио, несколько аккаунтов, выбор темы, журнал и «Что нового».
- **Интеграция с Android:** фоновое управление, быстрые действия, виджет, ссылки `tune://`, Android Auto и системный выбор аудиовыхода начиная с Android 14.

## Обновления

Tune автоматически проверяет [ленту обновлений](https://github.com/tune-music/tune-android/releases/latest/download/update.json) при открытии приложения. Найденное обновление появляется в настройках и коллекции; в настройках можно запустить проверку вручную. Кнопка скачивания открывает APK в браузере, после чего установку подтверждают в Android.

Для другого канала обновлений передайте в Gradle `-PtuneUpdateFeedUrl=https://example.org/tune/android.json`. Сборки, выпущенные до подключения ленты, нужно один раз обновить через APK из релиза.

```json
{
  "packageName": "music.tune.android",
  "versionCode": 14,
  "versionName": "0.2.12",
  "apkUrl": "https://github.com/tune-music/tune-android/releases/download/v0.2.12/Tune-Android-0.2.12.apk",
  "notes": "Включена автоматическая проверка обновлений."
}
```

## Сборка

Установите JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Откройте проект в Android Studio или укажите путь к SDK через `ANDROID_HOME`.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

Для проверки на устройстве нужны аккаунт Яндекса и доступ к каталогу. Отдельного прогона требуют Яндекс Станции, перенос очереди Ynison, Android Auto и звучание переходов.

### Релиз

При публикации увеличьте `versionCode`, соберите `gradlew :app:assembleRelease` и подпишите release APK. Добавьте подписанный APK и `update.json` в один релиз GitHub и назначьте его последним. В JSON укажите URL APK с тегом релиза.

Для совместимости с первыми сборками используется цепочка сертификатов APK v3 с переходом на релизный сертификат начиная с Android 9. При следующих публикациях сохраняйте цепочку и используйте те же ключи для поддерживаемых версий Android. Файлы ключей и пароли хранятся вне репозитория.
